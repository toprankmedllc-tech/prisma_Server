## Vignette

A laboratory evaluates a new automated assay for serum potassium. A gold-standard method defines the true serum potassium concentration as 4.2 mmol/L.

The new assay is tested on repeated samples and produces the following results (mmol/L):

3.6, 3.6, 3.7, 3.6, 3.5, 3.7, 3.6

The laboratory notes minimal variability between repeated measurements, but all values consistently differ from the reference method.

Which of the following best describes this assay?
