## Buzzword Question

Researchers find that coffee drinking is associated with lung cancer in an observational study. Upon further analysis, cigarette smoking is identified as a confounder, it is associated with both coffee drinking and lung cancer. Which of the following methods is used AFTER data collection to control for confounding?


## Buzzwords Used

Coffee and lung cancer; cigarette smoking confounds; after data collection; control for confounder


## Answer Options

A) Stratified analysis (stratify results by smoking status and examine the association within each stratum) 
B) Randomization (randomly assign participants to coffee-drinking groups) 
C) Restriction (enroll only non-smokers in the study) 
D) Matching (pair each coffee drinker with a non-drinker of the same smoking status)


## Correct Answer

A

## Explanation

Methods to control for confounding can be applied at the design stage or analysis stage. Design-stage methods (applied BEFORE/DURING data collection): randomization (eliminates confounding by distributing confounders equally), restriction (limit enrollment to exclude the confounder), matching (pair participants on confounder). Analysis-stage methods (applied AFTER data collection): stratified analysis (examine exposure-outcome association within strata of the confounder), multivariate regression (statistically adjust for multiple confounders simultaneously), standardization. Since the question specifies after data collection, stratified analysis is the correct answer.

## Buzzword Combination (Correct)

After data collection: stratification, multivariate regression, standardization; Before data collection: randomization, restriction, matching

## Wrong Options

### B) Randomization (randomly assign participants to coffee-drinking groups)

Randomization is a design-stage method applied BEFORE data collection. It eliminates confounding by randomly distributing both known and unknown confounders equally between groups. Once data collection is complete, you cannot retrospectively randomize participants.

**Buzzword Combo:** Randomization = design-stage, before data collection; eliminates all confounders (known + unknown) by equal distribution

### C) Restriction (enroll only non-smokers in the study)

Restriction is a design-stage method applied at enrollment, before data collection begins. By restricting enrollment to non-smokers, smoking cannot confound the association. However, this limits generalizability (external validity) and cannot be applied after data collection is complete.


**Buzzword Combo:** Restriction = design-stage; eliminates confounding but reduces generalizability; cannot be done retroactively

### D) Matching (pair each coffee drinker with a non-drinker of the same smoking status)


Matching is a design-stage method applied during participant selection, before data collection. Each exposed subject is paired with an unexposed subject with the same confounder value, balancing the confounder between groups by design.

**Buzzword Combo:** Matching = design-stage; pairs exposed + unexposed on confounder value before enrollment; requires matched analysis (McNemar's for case-control)
