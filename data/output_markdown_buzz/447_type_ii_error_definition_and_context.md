## Buzzword Question

A pharmaceutical trial comparing two antidepressants enrolls 40 patients per arm (n=40/group, power=45%). The result is p = 0.11, and the investigators conclude there is no difference between drugs. An independent analyst, however, finds that a 5-point HDRS difference truly exists in the real-world population. The result of this trial best represents:

## Buzzwords Used

p = 0.11 > alpha = 0.05; fail to reject H0; true difference exists; small sample; low power 45%

## Answer Options

A) Type II error — failed to reject a false null hypothesis 
B) Type I error — rejected a true null hypothesis 
C) Correct decision — null hypothesis is truly true 
D) Correct rejection of the null hypothesis

## Correct Answer

A

## Explanation

Type II error (beta error) occurs when the null hypothesis is FALSE (a true difference actually exists) but the study FAILS to reject it a false negative. Here: a true 5-point HDRS difference exists (H0 is false), but the underpowered study missed it (p = 0.11 > 0.05, fail to reject H0). This is a classic Type II error driven by inadequate sample size.

## Buzzword Combination (Correct)

H0 is false (true difference exists) + fail to reject H0 + p > alpha = Type II error (false negative)


## Wrong Options

### B) Type I error — rejected a true null hypothesis

A Type I error requires REJECTING a TRUE H0. In this study, H0 was NOT rejected (p > alpha, fail to reject). Type I and II errors cannot occur simultaneously on the same decision - one involves incorrect rejection, the other involves incorrect acceptance.


**Buzzword Combo:**  H0 is true + H0 rejected + p < alpha = Type I error (false positive); probability = alpha

### C) Correct decision — null hypothesis is truly true


The null hypothesis is NOT truly true here  a 5-point real-world difference exists. Failing to reject H0 when it is false is an error, not a correct decision. A correct decision would either be: (1) rejecting a false H0 (correct), or (2) failing to reject a true H0 (correct).

**Buzzword Combo:** H0 is true + fail to reject H0 = Correct decision (no error); probability = 1 − alpha

### D) Correct rejection of the null hypothesis


H0 was NOT rejected in this study (p = 0.11 > 0.05). The conclusion was 'no significant difference.' There was no rejection  correct or otherwise. Correct rejection requires p < alpha and H0 being false.

**Buzzword Combo:** H0 is false + correctly rejected (p < alpha) = Correct decision; probability = statistical power (1 − beta)
