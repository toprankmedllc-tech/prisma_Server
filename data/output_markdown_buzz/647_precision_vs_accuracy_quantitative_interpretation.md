## Buzzword Question

A gold-standard laboratory method measures serum potassium with a true value of 4.2 mmol/L (95% CI: 4.1–4.3). A new assay is evaluated using repeated measurements on the same sample.

Which of the following sets of repeated results best represents a test that is more accurate but less precise than the gold-standard method?

## Buzzwords Used

Gold standard ; Confidence interval ; Repeated measurements ; Accuracy ; Precision

## Answer Options

A) 4.15, 4.25, 4.10, 4.30, 4.20, 4.18
B) 4.20, 4.19, 4.21, 4.18, 4.22, 4.20
C) 3.60, 3.65, 3.58, 3.62, 3.60, 3.63
D) 4.80, 3.90, 4.50, 3.70, 4.10, 5.00

## Correct Answer

A) 4.15, 4.25, 4.10, 4.30, 4.20, 4.18

## Explanation

Option A has a mean close to the gold-standard value of 4.2, indicating good accuracy. However, the spread of values is relatively wide compared with option B, indicating lower precision.

## Buzzword Combination (Correct)

mean close to true value + wider spread = more accurate but less precise

## Wrong Options

### B) 4.20, 4.19, 4.21, 4.18, 4.22, 4.20

This shows both tight clustering and values centered on the true value, indicating high precision and high accuracy.

**Buzzword Combo:** tight clustering + correct mean = both accurate and precise

### C) 3.60, 3.65, 3.58, 3.62, 3.60, 3.63

This shows tight clustering but a consistent deviation from the true value, indicating precision without accuracy.

**Buzzword Combo:** tight clustering + wrong mean = precise but not accurate

### D) 4.80, 3.90, 4.50, 3.70, 4.10, 5.00

This shows wide variability and no consistent proximity to the true value, indicating low precision and low accuracy.

**Buzzword Combo:** wide spread + inconsistent mean = neither accurate nor precise

## Related Concepts

Systematic error ; Random error ; Confidence interval interpretation

## Tags

Accuracy reflects closeness of measurements to the true value, while precision reflects how close repeated measurements are to each other. A test can be accurate on average but still lack precision if results are widely scattered.
