## Buzzword Question

A hospital uses the same screening test for Disease Y in two different populations. The test has identical sensitivity and specificity in both settings. Population A consists of patients referred to a specialty clinic where Disease Y is common. Population B consists of asymptomatic individuals undergoing routine community screening where Disease Y is rare.

Which of the following is most likely to be true?

## Buzzwords Used

Disease prevalence ; Specialty clinic ; Community screening ; Positive predictive value ; Diagnostic testing

## Answer Options

A) A positive test result is more likely to represent true disease in Population A

B) A negative test result is more likely to represent true disease in Population A

C) The sensitivity of the test is higher in Population A

D) The specificity of the test is higher in Population B

## Correct Answer

A) A positive test result is more likely to represent true disease in Population A

## Explanation

Positive predictive value increases as disease prevalence increases. Therefore, a positive test result is more likely to represent true disease in the higher-prevalence population.

## Buzzword Combination (Correct)

Higher prevalence + unchanged sensitivity/specificity + positive result = higher PPV

## Wrong Options

### B) A negative test result is more likely to represent true disease in Population A

Negative predictive value generally decreases as disease prevalence increases.

**Buzzword Combo:** Higher prevalence + negative test result + confusion with NPV = incorrect conclusion

### C) The sensitivity of the test is higher in Population A

Sensitivity is an intrinsic characteristic of a test and does not change with disease prevalence.

**Buzzword Combo:** Different population + unchanged test characteristics = sensitivity unchanged

### D) The specificity of the test is higher in Population B

Specificity is also an intrinsic characteristic of a test and is unaffected by prevalence.

**Buzzword Combo:** Different prevalence + same diagnostic test = specificity unchanged
