## Buzzword Question

A laboratory evaluates a new diagnostic assay for detecting hyperkalemia. The test consistently identifies most patients who truly have elevated potassium levels but also frequently classifies patients without hyperkalemia as positive. In a separate validation, the test values show tight clustering across repeated runs on the same sample.

Which of the following best describes the performance of this test?

## Buzzwords Used

True positives ; False positives ; Repeated testing ; Tight clustering ; Diagnostic performance

## Answer Options

A) High sensitivity with low specificity
B) High specificity with low sensitivity
C) High accuracy with low precision
D) Low sensitivity with high specificity

## Correct Answer

A) High sensitivity with low specificity

## Explanation

The test correctly identifies most true cases (high sensitivity) but also produces many false positives (low specificity). The repeated measurements being tightly clustered describe precision, which is separate from diagnostic classification performance.

## Buzzword Combination (Correct)

high true positive detection + many false positives = high sensitivity, low specificity

## Wrong Options

### B) High specificity with low sensitivity

This would mean the test correctly excludes non-diseased individuals but misses many true cases, which is not described.

**Buzzword Combo:** few false positives + many false negatives = not applicable

### C) High accuracy with low precision

Accuracy and precision refer to measurement properties, not diagnostic classification rates like sensitivity and specificity.

**Buzzword Combo:** measurement closeness concepts ≠ diagnostic test characteristics

### D) Low sensitivity with high specificity

This would imply many missed true cases and few false positives, which contradicts the stem.

**Buzzword Combo:** missed cases + few false positives = opposite pattern
