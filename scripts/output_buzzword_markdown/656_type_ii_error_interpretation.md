## Buzzword Question

A clinical trial evaluates whether a new antihypertensive drug reduces blood pressure compared with placebo. After analysis, investigators conclude that there is no statistically significant difference and therefore do not reject the null hypothesis. Later, it is discovered that the drug actually does have a clinically meaningful effect in the population.

Which of the following best describes this situation?

## Buzzwords Used

Null hypothesis ; Statistical significance ; Treatment effect ; Clinical trial ; Hypothesis testing

## Answer Options

A) Type I error
B) Type II error
C) Increased statistical power
D) Random sampling error

## Correct Answer

B) Type II error

## Explanation

The study failed to reject the null hypothesis despite a true effect existing in the population. This represents a failure to detect an actual difference.

## Buzzword Combination (Correct)

true effect missed + no rejection of null = Type II error

## Wrong Options

### A) Type I error

Type I error occurs when a true null hypothesis is incorrectly rejected.

**Buzzword Combo:** false positive logic = wrong direction

### C) Increased statistical power

Higher power would reduce the likelihood of missing a true effect, not describe this outcome.

**Buzzword Combo:** low power scenario = missed detection

### D) Random sampling error

Random sampling error contributes to variability but does not define systematic failure to detect a true effect.

**Buzzword Combo:** sampling variability ≠ hypothesis testing error
