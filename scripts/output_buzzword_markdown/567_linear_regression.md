## Buzzword Question

Researchers are investigating whether there is a positive relationship between caffeine intake and reaction time among university students. The principal investigator states that the aim is to determine whether higher caffeine consumption is associated with faster reaction times.

Which of the following is the most appropriate approach to analyze this research question?

## Buzzwords Used

Caffeine intake ; Reaction time ; Relationship ; Continuous variables ; Association

## Answer Options

A) Rank caffeine intake and reaction time for all participants and assess whether higher ranks in caffeine correspond to lower ranks in reaction time

B) Model reaction time as the outcome variable and estimate how it changes with increasing caffeine intake using a fitted mathematical equation

C) Divide participants into caffeine intake categories and compare mean reaction times across the groups

D) Convert both caffeine intake and reaction time into binary categories and test for an association between them

## Correct Answer

B) Model reaction time as the outcome variable and estimate how it changes with increasing caffeine intake using a fitted mathematical equation

## Explanation

Linear regression is used to model the relationship between a continuous exposure and a continuous outcome. It estimates how changes in caffeine intake are associated with changes in reaction time using a fitted predictive equation.

## Buzzword Combination (Correct)

Continuous exposure + continuous outcome + predictive modeling = linear regression

## Wrong Options

### A) Rank caffeine intake and reaction time for all participants and assess whether higher ranks in caffeine correspond to lower ranks in reaction time

This describes a rank-based non-parametric approach (Spearman correlation), which is not the most appropriate method when analyzing continuous variables without transformation.

**Buzzword Combo:** Ranked data + monotonic relationship assessment = Spearman correlation

### C) Divide participants into caffeine intake categories and compare mean reaction times across the groups

This unnecessarily categorizes a continuous variable and compares group means instead of analyzing the continuous relationship.

**Buzzword Combo:** Continuous exposure → grouping → mean comparison = t-test/ANOVA

### D) Convert both caffeine intake and reaction time into binary categories and test for an association between them

This reduces continuous variables into categorical forms, leading to loss of information and an inappropriate analytical approach.

**Buzzword Combo:** Both variables categorized + association testing = Chi-square test
