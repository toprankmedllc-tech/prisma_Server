## Buzzword Question

A chemotherapy drug used against rapidly dividing cells also has use as a disease-modifying agent in rheumatoid arthritis. It decreases tetrahydrofolate availability, reducing thymidine and purine synthesis. Which enzyme is most directly inhibited by this drug?

## Buzzwords Used

Rapidly dividing cells; decreased tetrahydrofolate availability; reduced thymidine and purine synthesis

## Answer Options

A) Dihydrofolate reductase
B) Thymidylate synthase
C) Ribonucleotide reductase
D) IMP dehydrogenase

## Correct Answer

A) Dihydrofolate reductase


## Explanation

Methotrexate inhibits dihydrofolate reductase, decreasing tetrahydrofolate production. This reduces thymidine and purine synthesis and impairs DNA synthesis in rapidly dividing cells.

## Buzzword Combination (Correct)

Rapidly dividing cells + decreased tetrahydrofolate + impaired thymidine synthesis = methotrexate

## Wrong Options

### B) Thymidylate synthase

This describes 5-fluorouracil, which directly inhibits thymidylate synthase. Methotrexate acts earlier by inhibiting dihydrofolate reductase.

**Buzzword Combo:** Pyrimidine analog + decreased dTMP synthesis + thymidylate synthase inhibition = 5-fluorouracil

### C) Ribonucleotide reductase

This describes hydroxyurea. It decreases deoxyribonucleotide production rather than tetrahydrofolate production.

**Buzzword Combo:** Blocks ribonucleotides to deoxyribonucleotides + S-phase inhibition + increased fetal hemoglobin = hydroxyurea

### D) IMP dehydrogenase

This describes mycophenolate, which inhibits guanine nucleotide synthesis. It does not block folate-dependent thymidine synthesis.

**Buzzword Combo:** Guanine nucleotide depletion + lymphocyte suppression + transplant immunosuppression = mycophenolate

## Related Concepts

5-fluorouracil; hydroxyurea; mycophenolate
