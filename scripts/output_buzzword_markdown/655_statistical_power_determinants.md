## Buzzword Question

A randomized controlled trial is being designed to evaluate a new lipid-lowering drug. Investigators are considering changes to the study design to improve its ability to detect a true treatment effect.

Which of the following is most likely to increase statistical power?

## Buzzwords Used

Sample size ; Measurement precision ; Statistical power ; Variability ; Effect detection

## Answer Options

A) Decrease sample size
B) Increase measurement precision
C) Increase Type I error threshold
D) Decrease expected effect size

## Correct Answer

B) Increase measurement precision

## Explanation

Improving measurement precision reduces variability in outcome measurement, making it easier to detect true differences between groups, thereby increasing statistical power.

## Buzzword Combination (Correct)

reduced variability + better measurement accuracy = increased power

## Wrong Options

### A) Decrease sample size

Reducing sample size lowers statistical power and increases the risk of missing a true effect.

**Buzzword Combo:** smaller n = lower power

### C) Increase Type I error threshold

This affects α level, not directly measurement precision or study power in a clinically meaningful way.

**Buzzword Combo:** higher α = more false positives, not power improvement focus

### D) Decrease expected effect size

A smaller expected effect makes detection harder and decreases power.

**Buzzword Combo:** smaller effect size = lower detectability
