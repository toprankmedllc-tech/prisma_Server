## Buzzword Question

A researcher wants to increase statistical power in a planned clinical trial from 60% to 80%. She is considering several design modifications. Which of the following changes would MOST directly increase statistical power?

## Buzzwords Used

Power 60% to 80%; planning phase; design modification; increase power

## Answer Options

A) Increase sample size 
B) Decrease the significance threshold from alpha = 0.05 to alpha = 0.01 
C) Use a two-tailed instead of one-tailed test 
D) Increase the number of outcome measures tested

## Correct Answer

A

## Explanation

Statistical power = 1 − β (probability of correctly rejecting a false null hypothesis). Power is determined by: (1) sample size — the strongest modifiable determinant, larger N directly increases power; (2) effect size — larger true differences are easier to detect; (3) alpha level — higher alpha (e.g., 0.10 vs 0.05) increases power at the cost of increased Type I error; (4) variability — lower outcome variability increases power. Increasing sample size is the most direct and reliable method to increase power from 60% to 80% without inflating Type I error.

## Buzzword Combination (Correct)

Power = 1 - beta; increased by: ↑ N, ↑ effect size, ↑ alpha, ↓ variability; sample size = most direct modifiable factor


## Wrong Options

### B) Decrease the significance threshold from alpha = 0.05 to alpha = 0.01

DECREASING alpha (making the criterion more stringent) DECREASES power by making it harder to reject the null hypothesis  it INCREASES beta (Type II error). To increase power by manipulating alpha, one would need to INCREASE alpha (e.g., from 0.05 to 0.10), which is generally not acceptable as it raises Type I error risk.



**Buzzword Combo:** ↓ alpha → ↓ power (↑ beta); ↑ alpha → ↑ power (↓ beta); inverse relationship between alpha stringency and power

### C) Use a two-tailed instead of one-tailed test

Switching from one-tailed to two-tailed testing DECREASES power for a specific direction of effect, because the critical region is split between both tails. A one-tailed test has more power to detect an effect in the specified direction but cannot detect effects in the opposite direction. Two-tailed tests are generally preferred for scientific rigor despite the modest power cost.

**Buzzword Combo:** One-tailed test → ↑ power for specified direction; two-tailed test → ↓ power per direction but tests both; switching to two-tailed ≠ ↑ power

### D) Increase the number of outcome measures tested


Increasing the number of outcomes tested increases Type I error (familywise error rate) and necessitates corrections (e.g., Bonferroni) that reduce effective alpha  which DECREASES power. More outcomes tested does not increase the power of detecting any single primary outcome.


**Buzzword Combo:** More outcomes tested → ↑ Type I error → requires alpha correction → ↓ power per test
