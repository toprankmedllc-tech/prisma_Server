## Buzzword Question

In a validation study of a new tuberculin skin test, 400 patients are enrolled. Of the 80 patients with confirmed active TB, 72 test positive and 8 test negative. Of the 320 patients without TB, 32 test positive and 288 test negative. The sensitivity of this test is:

## Buzzwords Used

80 disease-positive; 72 true positives; 8 false negatives; 320 disease-negative

## Answer Options

A) 90%
 B) 72% 
C) 80% 
D) 69%

## Correct Answer

A

## Explanation

Sensitivity = TP/(TP+FN) = 72/(72+8) = 72/80 = 0.90 = 90%. This represents the proportion of truly TB-positive patients correctly identified by the test. The 320 disease-negative patients and their results are not used in the sensitivity calculation.

## Buzzword Combination (Correct)

TP/(TP+FN) × 100 = Sensitivity = proportion of diseased patients correctly identified

## Wrong Options

### B) 72%

72% confuses the raw TP count (72) with the percentage. Sensitivity = 72/80 = 90%, not 72%. The denominator must be all disease-positive patients (TP+FN = 80), not the TP count alone.

**Buzzword Combo:** Raw TP count ≠ sensitivity percentage  must divide by total disease-positive (TP+FN)

### C) 80%

80% uses the total number of disease-positive patients (80) as the percentage rather than performing the actual calculation 72/80 = 90%. This is a common arithmetic error.

**Buzzword Combo:** Total disease-positive count ≠ sensitivity . sensitivity = TP/(TP+FN) × 100

### D) 69%

69% is the PPV = TP/(TP+FP) = 72/(72+32) = 72/104 ≈ 69%. This confuses sensitivity (uses disease column) with PPV (uses test-positive row). Sensitivity = 90%, not 69%.

**Buzzword Combo:** TP/(TP+FP) = PPV (not sensitivity) — sensitivity uses disease column, PPV uses test-positive row
