## Buzzword Question

A child develops fever, diffuse rash, joint pain, and mild proteinuria 1 week after receiving a foreign protein-containing medication. Which of the following hypersensitivity reactions best explains this presentation?

## Buzzwords Used

Fever and diffuse rash; joint pain; mild proteinuria after foreign protein exposure

## Answer Options

A) Type III hypersensitivity
B) Type I hypersensitivity
C) Type II hypersensitivity
D) Type IV hypersensitivity

## Correct Answer

A) Type III hypersensitivity


## Explanation

Type III hypersensitivity is mediated by circulating antigen-antibody complexes that deposit in tissues, activate complement, and recruit neutrophils. Serum sickness classically presents with fever, rash, arthralgia, and possible proteinuria.

## Buzzword Combination (Correct)

Fever/rash + arthralgia + proteinuria after foreign antigen exposure = type III hypersensitivity

## Wrong Options

### B) Type I hypersensitivity

Type I hypersensitivity is mediated by IgE cross-linking on mast cells and basophils, causing immediate allergic reactions. It does not primarily involve tissue deposition of circulating immune complexes.

**Buzzword Combo:** Immediate reaction + IgE cross-linking + mast cell degranulation = type I hypersensitivity

### C) Type II hypersensitivity

Type II hypersensitivity is mediated by IgG or IgM antibodies against fixed antigens on cells, tissues, or receptors. It does not match the systemic immune complex pattern.

**Buzzword Combo:** IgG/IgM against cell-surface antigen + complement activation + cell/tissue injury = type II hypersensitivity

### D) Type IV hypersensitivity

Type IV hypersensitivity is delayed and T-cell mediated. It is associated with contact dermatitis, tuberculin skin test reactions, and granulomatous inflammation.

**Buzzword Combo:** Delayed reaction + T-cell mediated injury + macrophage activation = type IV hypersensitivity
