## Buzzword Question

A screening test for Disease X is administered to 1,000 individuals. Among the 120 patients who test positive, 90 are ultimately confirmed to have the disease. Among the 880 patients who test negative, 10 are later found to have the disease.

Which of the following is the positive predictive value of the test?

## Buzzwords Used

Screening test ; True positives ; Positive test results ; Diagnostic testing ; Positive predictive value

## Answer Options

A) 90/100

B) 90/120

C) 90/1000

D) 120/1000

## Correct Answer

B) 90/120

## Explanation

Positive predictive value is the probability that a patient truly has the disease given a positive test result. It is calculated as true positives divided by all positive test results.

## Buzzword Combination (Correct)

Positive test results + true disease among positives + probability of disease given a positive test = PPV

## Wrong Options

### A) 90/100

This denominator does not represent all positive test results and therefore does not calculate PPV correctly.

**Buzzword Combo:** True positives + incomplete positive-test denominator = incorrect PPV calculation

### C) 90/1000

This uses the total study population as the denominator and does not represent positive predictive value.

**Buzzword Combo:** True positives + total population denominator = prevalence-style calculation

### D) 120/1000

This calculates the proportion of positive test results in the population rather than the probability of disease given a positive test.

**Buzzword Combo:** All positive tests + total population = test positivity rate
