## Buzzword Question

A fatigued intern writes an order for 10-fold the correct morphine dose. The pharmacist, overwhelmed by high volume, approves it without catching the error. The patient receives the overdose and suffers respiratory depression. Which of the following correctly classifies the contributing factors in this event?

## Buzzwords Used

Fatigued intern; 10-fold morphine overdose; overwhelmed pharmacist; order approved; respiratory depression; multiple system failures


## Answer Options

A) The intern's erroneous order is an active error; the systemic factors (fatigue policy, understaffing, lack of dose-limit alerts) are latent errors 
B) The pharmacist's failure to catch the error is a latent error; the intern's order is not classifiable as an error 
C) Both the intern's and pharmacist's errors are latent errors because they reflect systemic problems 
D) The event represents a near-miss because the patient ultimately recovered

## Correct Answer

A

## Explanation

In the Swiss Cheese Model (Reason), errors are classified as active or latent. Active errors occur at the point of contact between a human and a system, the intern's erroneous order entry is the active (sharp-end) error. Latent errors are upstream system vulnerabilities that create conditions for active errors: fatigued workforce (inadequate scheduling), understaffing (pharmacist overload), absent hard-stop dose alerts, and absent independent double-check protocols. Latent errors are the 'holes in the cheese slices'; when holes align, harm reaches the patient. Root cause analysis focuses on identifying and fixing latent errors rather than blaming the frontline provider.

## Buzzword Combination (Correct)

 Active error = sharp-end human mistake at point of care (intern's order); Latent error = upstream system vulnerability (fatigue, staffing, absent alerts)

## Wrong Options

### 1: B) The pharmacist's failure to catch the error is a latent error; the intern's order is not classifiable as an error

The pharmacist's failure is also an active error,  it occurred at the point of care during real-time decision-making. Both the intern's order and the pharmacist's approval failure are active errors. The systemic conditions enabling both failures (understaffing, absent alerts) are the latent errors.

**Buzzword Combo:** Both frontline failures = active errors; system conditions enabling them = latent errors; pharmacist failure ≠ latent error

### 2: C) Both the intern's and pharmacist's errors are latent errors because they reflect systemic problems

Errors made by frontline providers at the point of care are active errors regardless of the systemic conditions that contributed. Latent errors are the pre-existing system-level vulnerabilities, not the human actions themselves. The Swiss Cheese model distinguishes these precisely to direct corrective action toward systems rather than individual blame.

**Buzzword Combo:** Active = frontline human action errors; Latent = pre-existing system vulnerabilities; do not conflate

### 3: D) The event represents a near-miss because the patient ultimately recovered


A near-miss is an event that COULD have caused harm but did not reach the patient (e.g., the error was caught before administration). In this case, the patient received the overdose and suffered respiratory depression, this is an adverse event (sentinel event), not a near-miss. Recovery after the event does not change the classification

**Buzzword Combo:** Near-miss = error did not reach patient; Adverse event = error reached patient causing harm; Sentinel event = serious unexpected harm
