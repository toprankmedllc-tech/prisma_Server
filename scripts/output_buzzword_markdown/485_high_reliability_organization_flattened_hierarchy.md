## Buzzword Question

During morning ICU rounds, a pharmacist notices that vancomycin has been ordered at a standard dose for a patient with a creatinine of 4.2 mg/dL requiring significant renal dose adjustment. The pharmacist immediately notifies the attending physician before administration, preventing potential nephrotoxicity and supratherapeutic drug accumulation. This behavior most directly reflects which principle of high-reliability organizations?

## Buzzwords Used

Any team member speaks up; caught before harm; pharmacist challenges physician order; psychological safety; hierarchy flattened; prevention


## Answer Options

A) Sensitivity to operations and deference to expertise / flattened hierarchy 
B) Implementation of a system-level forcing function 
C) Retrospective root cause analysis of a near-miss event 
D) Proactive failure mode and effects analysis

## Correct Answer

A

## Explanation

High-reliability organizations (HROs) maintain two key safety principles demonstrated here: (1) Sensitivity to operations, all team members, regardless of role, actively monitor for unsafe conditions at the point of care; (2) Flattened hierarchy / deference to expertise, any team member can and should raise safety concerns without fear of retaliation (psychological safety), with authority to stop care when concerned. The pharmacist's cross-hierarchical challenge of a physician order embodies both principles.

## Buzzword Combination (Correct)

Any team member monitors for safety + speaks up regardless of rank + no fear of retaliation = HRO sensitivity to operations + flattened hierarchy + psychological safety

## Wrong Options

### 1: B) System-level forcing function

A forcing function is a system design feature that physically prevents an error, such as weight-based dosing calculators requiring renal function input before generating a dose, or incompatible connectors. The pharmacist's verbal intervention is a behavioral/cultural safety behavior. If the EHR had automatically blocked the order pending creatinine input, that would be a forcing function.

**Buzzword Combo:** System design physically prevents error completion (incompatible connectors, locked fields) = Forcing function


### 2: C) Retrospective root cause analysis

RCA is conducted AFTER an adverse event has caused harm, it is retrospective and investigative. This scenario involves real-time prevention of harm before it reaches the patient, proactive bedside safety behavior, not retrospective investigation.

**Buzzword Combo:** After harm occurs + systematic investigation of contributing system failures = Root cause analysis (retrospective)

### 3: D) Proactive failure mode and effects analysis

FMEA is a formal, structured, pre-planned prospective analysis of a process to identify potential failure modes, conducted by a team examining a process flowchart, not at the bedside in real time. The pharmacist's intervention is an individual safety behavior, not a formal FMEA process.

**Buzzword Combo:** Formal structured team analysis of process failure modes before event = FMEA (prospective, not real-time bedside)
