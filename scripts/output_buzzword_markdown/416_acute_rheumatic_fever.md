## Buzzword Question

Acute rheumatic fever results from cross-reactive antibodies generated against streptococcal M protein that bind host tissue antigens. This is an example of which type of hypersensitivity reaction?

## Buzzwords Used

Acute rheumatic fever; cross-reactive antibodies; streptococcal M protein

## Answer Options

A) Type I (IgE-mediated)
B) Type II (antibody-mediated)
C) Type III (immune complex–mediated)
D) Type IV (T-cell–mediated, delayed)

## Correct Answer

B) Type II (antibody-mediated)

## Explanation

Acute rheumatic fever is a type II hypersensitivity reaction. Antibodies raised against streptococcal M protein cross-react with structurally similar host antigens in the heart, joints, skin, and brain — the mechanism of molecular mimicry.

## Buzzword Combination (Correct)

Molecular mimicry + cross-reactive antibodies vs. M protein = type II hypersensitivity (ARF)
