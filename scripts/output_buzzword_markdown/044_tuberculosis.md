## Buzzword Question

A man with hemoptysis is found to have acid-fast bacilli on Ziehl-Neelsen staining. Which bacterial cell wall component is responsible for acid-fast staining properties?


## Buzzwords Used

Hemoptysis; Acid-fast; Ziehl-Neelsen


## Answer Options

A) Mycolic acids
B) Lipopolysaccharide
C) Teichoic acid
D) Polyribitol phosphate capsule

## Correct Answer

A) Mycolic acids

## Explanation

Tuberculosis organisms contain mycolic acids within their cell wall, giving them acid-fast staining properties. These waxy long-chain fatty acids allow the bacteria to retain carbol fuchsin dye despite acid-alcohol decolorization.

## Buzzword Combination (Correct)

Acid-fast bacilli + carbol fuchsin retention + waxy cell wall = Mycolic acids

## Wrong Options

###  Lipopolysaccharide

Lipopolysaccharide is an endotoxin found in gram-negative bacteria and is not responsible for acid-fast staining.

**Buzzword Combo:** Gram-negative bacteria + endotoxin + lipid A = Lipopolysaccharide

### Teichoic acid

Teichoic acids are found in gram-positive bacterial cell walls.

**Buzzword Combo:** Peptidoglycan layer + teichoic acids = Gram-positive cell wall


### Polyribitol phosphate capsule

Polyribitol phosphate is the capsule component of Haemophilus influenzae type b.

**Buzzword Combo:** Meningitis + epiglottitis + PRP capsule = H. influenzae type b
