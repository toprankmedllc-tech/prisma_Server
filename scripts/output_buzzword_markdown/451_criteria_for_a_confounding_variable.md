## Buzzword Question

In a cohort study, alcohol consumption is found to be associated with esophageal cancer. Cigarette smoking is found to be strongly associated with both alcohol use and esophageal cancer, and smoking precedes both alcohol use and esophageal cancer in the temporal sequence. The tobacco variable satisfies all three criteria for a confounder. Those criteria are:

## Buzzwords Used

Associated with exposure (alcohol); independent risk factor for outcome (esophageal cancer); not on causal pathway from alcohol to cancer

## Answer Options

A) Associated with exposure + independently associated with outcome + not an intermediate variable on the causal pathway 
B) Causes the exposure + causes the outcome + is measured before the outcome 
C) Present in cases + absent in controls + detected only retrospectively 
D) Associated with the outcome + modifies the effect of the exposure + differs between strata

## Correct Answer

A

## Explanation

The three necessary and sufficient criteria for a confounding variable are: (1) it is associated with the exposure (tobacco use is associated with alcohol consumption); (2) it is an independent risk factor for the outcome (tobacco independently causes esophageal cancer); (3) it is not an intermediate variable on the causal pathway between exposure and outcome (tobacco causes esophageal cancer through its own mechanisms, not by causing alcohol use).

## Buzzword Combination (Correct)

Associated with exposure + independent outcome risk factor + not on causal pathway = Confounder (all 3 criteria required)

## Wrong Options

### B) Causes the exposure + causes the outcome + is measured before the outcome

A confounder does not need to causally cause the exposure  it only needs to be associated with it. Temporal precedence (measured before outcome) is relevant for establishing causality but is not one of the three formal confounding criteria.

**Buzzword Combo:** 
Association ≠ causation for confounding; temporal precedence is a criterion for causality (Bradford Hill), not confounding definition

### C) Present in cases + absent in controls + detected only retrospectively

This describes features relevant to case-control study exposure patterns, not the formal definition of a confounder. A confounder can be present in both cases and controls and can be measured prospectively.

**Buzzword Combo:** Cases have exposure + controls lack exposure = OR > 1 in case-control; this describes differential exposure, not confounding definition

### D) Associated with the outcome + modifies the effect of the exposure + differs between strata


Effect modification (interaction)  not confounding  occurs when the magnitude or direction of an exposure's effect differs across strata of a third variable. Effect modification is a true biological phenomenon to be reported; confounding is a bias to be controlled. They require different analytic responses.

**Buzzword Combo:** Exposure effect differs across strata of third variable = Effect modification (interaction)  to be reported, not removed
